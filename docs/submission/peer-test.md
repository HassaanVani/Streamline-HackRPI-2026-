# Five-person comprehension check

Status: **not conducted — owner reports participants unavailable**. Target audience: people without aviation expertise. Use anonymous IDs P1–P5; collect no names, contacts, or recordings. Allow roughly 3 minutes per participant. Don't teach the explanation before testing it.

## Facilitator instructions

Start on the quiet JFK–LHR map with model winds enabled and progress reset. Say: “Explore what wind does to a journey. Think aloud if you can.” Let the participant find the invitation; record whether they need a hint. Use these tasks:

1. Predict which Atlantic direction is quicker; open and run the experiment.
2. Explain the result in your own words. Ask what the 82-minute difference compares.
3. Return to Explore and explain what the roughly five-minute difference compares.
4. Find one limitation or excluded real-world constraint.
5. Choose another pair of airports; recognize that Calculate updates the displayed route.

Record correctness of the prediction separately from understanding. A wrong guess followed by a correct explanation demonstrates learning more clearly than a lucky guess alone. “Wind pushes one direction and opposes the reverse” is an acceptable causal explanation. Confusing 82 minutes with optimization savings is a comprehension failure. If needed, offer one neutral hint, record it, and continue.

Target: at least 4/5 complete the prediction–test–explain–return sequence without coaching and distinguish the two comparisons. Treat this as a practical acceptance target, not statistical proof. If the target is missed, fix the observed instruction/navigation issue and retest with available participants. Keep all failures in the record.
